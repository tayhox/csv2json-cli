# csv2json-cli

A small command-line tool that converts CSV files to JSON.

## Why this exists

CSV is common in data work, but JSON is easier to use in APIs and applications.
This tool provides a simple, dependency-free converter.

## Usage

```bash
python csv2json.py input.csv
python csv2json.py input.csv -o output.json
